# ALF-216 — drag an inbox task onto the folder it's labelled with

*2026-10-04T18:48:00.676Z*

The classifier labels an Inbox row with the folder it WOULD land in (here: Book the dentist → Work, Water the plants → Home) without dispatching it, so both still live in the Inbox.

![](alf-216-image-1.png)

Dragging Book the dentist onto Work — its own labelled folder. Before the fix the drop compared Work against the row's raw folder_id, read it as 'dropped where it already lives', and silently did nothing. The drop now compares against where the row actually lives (the Inbox).

![](alf-216-image-2.png)

On release the row leaves the Inbox immediately…

![](alf-216-image-3.png)

…and is filed in Work.
